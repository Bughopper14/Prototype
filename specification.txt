Functional Specification Document (FSD)
System: Heavy Equipment Loan Origination & Document Management System (LOS-DMS)
Document Version: 1.0.0
Target Audience: Frontend Engineers, Backend Engineers, QA Engineers, Database Architects
Domain Reference: PT LiuGong Finance Indonesia (Application Form & Document Check List)

1. Technical Architecture & Tech Stack Overview
1.1 Architecture Pattern
Pattern: Modular Monolith / Decoupled Client-Server (RESTful API Architecture).
Backend: Node.js (NestJS / TypeScript) atau Go / Python FastAPI.
Frontend: React / Next.js (TypeScript, Tailwind CSS, Shadcn UI / Ant Design).
Database: PostgreSQL 15+ (Relational with JSONB support for dynamic audit trails).
ORM / Query Builder: Prisma ORM / TypeORM / Drizzle.
Object Storage: S3-compatible storage (MinIO / AWS S3) for document binaries with pre-signed URL upload.
Authentication & AuthZ: JWT with Role-Based Access Control (RBAC).
2. Comprehensive Database Schema (Prisma / PostgreSQL DDL)
Berikut adalah definisi skema database relasional lengkap yang merefleksikan seluruh elemen formulir dan matriks dokumen.

model Customer {

  updatedAt       DateTime          @updatedAt @map("updated_at")

  @@map("customers")
}

model Application {
  id              String            @id @default(uuid())
  customerId      String            @map("customer_id")
  fapNumber       String            @unique @map("fap_number") @db.VarChar(50) // e.g. 001/AF/IX/2026

  companyAddress  String            @map("company_address") @db.Text

  postalCode      String            @map("postal_code") @db.VarChar(10)

3. Business Logic, Calculations & Validasi Data
3.1 Algoritma Penomoran FAP Otomatis
Format: {Sequential 3-digit}/AF/{Romawi Bulan}/{Tahun}.
Logika:
typescript

function generateFapNumber(nextSequence: number, date: Date = new Date()): string {
  const romanMonths = ['I', 'II', 'III', 'IV', 'V', 'VI', 'VII', 'VIII', 'IX', 'X', 'XI', 'XII'];
  const month = romanMonths[date.getMonth()];
  const year = date.getFullYear();
  const seqStr = String(nextSequence).padStart(3, '0');
  return `${seqStr}/AF/${month}/${year}`;
}

4. State Machine Workflow

[DRAFT] 
   │  (MKT completes Application Form & initial docs)
   ▼
[SUBMITTED_TO_BS]
   │  (BS verifies NIB, NPWP, Akta, Legalitas)
   ├──► [RETURNED] (Dokumen tidak lengkap -> MKT merevisi)
   ▼
[BS_VERIFIED]
   │  (Trigger parallel tasks: CA & Legal)
   ▼
[IN_CA_LEGAL_REVIEW]
   │  (CA completes Spreading & Legal issues Legal Opinion)
   ▼
[CREDIT_COMMITTEE_REVIEW]
   │
   ├──► [APPROVED]  ──► (Siap cetak Offering Letter / PK)
   └──► [REJECTED]  ──► (Aplikasi ditolak)

7. Security, Auditing & Error Handling Standards
Error Response Format (RFC 7807 Standard):
json

{
  "statusCode": 422,
  "error": "Unprocessable Entity",
  "message": "Validation failed",
  "errors": [
    {
      "field": "stakeholders",
      "detail": "Sum of shareholder percentage must be exactly 100%. Current sum: 95.50%"

Object Storage Security: Dokumen tidak boleh diakses lewat URL publik. Seluruh akses berkas wajib menggunakan Time-limited Pre-signed URL (maksimum validitas 15 menit).
Audit Trail Immutability: Tabel approval_logs bersifat append-only (tidak diizinkan operasi UPDATE atau DELETE).
